# Project Statement

## VIT BPL Bank

The **VIT BPL Bank** is a console-based banking application developed using **Java**. The project is designed to provide basic banking operations through a simple and user-friendly menu-driven interface.

The application allows users to **create bank accounts, deposit money, withdraw money, check account balances, and view all available accounts**. It also stores account and transaction details during the program execution.

The project uses fundamental Java concepts such as **classes, methods, ArrayList, Scanner, loops, conditional statements, and user input/output**. It is mainly developed for educational purposes to understand how basic banking operations can be implemented using Java programming.

### Objectives

* To develop a simple banking system using Java.
* To implement basic account and transaction operations.
* To practice fundamental Java programming concepts.
* To understand menu-driven application development.

### Conclusion

The VIT BPL Bank project provides a basic implementation of banking operations and serves as a practical example for learning and applying core Java programming concepts.
