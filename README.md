#  VIT BPL Bank

A simple **console-based banking application developed using Java**.

## Features

* Create bank accounts
* Deposit money
* Withdraw money
* Check account balance
* List all accounts

## Technologies

* Java
* ArrayList
* Scanner

## Run

```bash
javac VITBPLBank.java
java VITBPLBank
```

## Purpose

This project was created to practice **basic Java programming and banking operations**.
