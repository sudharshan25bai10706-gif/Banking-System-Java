# Banking-System-Java
VIT BPL Bank

A simple console-based banking application developed using Java.

Features
Create a bank account
Deposit money
Withdraw money
Check account balance
List all accounts
Exit the program
Technologies Used
Java
ArrayList
Scanner
How to Run

Compile the program:

javac VITBPLBank.java

Run the program:

java VITBPLBank
Project

This project is created for learning and demonstrating basic Java programming concepts.
